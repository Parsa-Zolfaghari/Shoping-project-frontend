## 📖 About The Project

**SunTime** is a modern watch e-commerce platform that allows users to discover and purchase watches through a convenient and feature-rich shopping experience.

The platform focuses on making product discovery easier through flexible filtering and search functionality, while also providing a dedicated administration system for managing the store and its operations.

SunTime is being developed as a full-stack application with a Vanilla JavaScript frontend and a Node.js/Express backend.
